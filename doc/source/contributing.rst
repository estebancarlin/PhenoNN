Contributing
============

How to Contribute
-----------------

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests
5. Submit a pull request

Development Setup
-----------------

.. code-block:: bash

   git clone https://github.com/kardaneh/PhenoNN.git
   cd PhenoNN
   uv venv
   source .venv/bin/activate
   uv pip install -e ".[dev]"
